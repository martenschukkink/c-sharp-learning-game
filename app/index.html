Code Gangen

Het gebouw ís het programma, van boven naar beneden. Elke regel code is een kamer: loop over het gloeiende vlak in het midden en de regel wordt uitgevoerd. Pas daarna gaat de glazen schuifdeur naar de volgende kamer open.

Declaratie: nieuwe variabele
Toekenning: waarde wijzigen
Conditie: reken hem zelf uit
Onderdelen van een loop
Deuren true / false: kies er één
Schuifdeur: open na de regel, terug kan niet
Lopende band: brengt je naar de volgende regel
Uitvoer verschijnt in de console
